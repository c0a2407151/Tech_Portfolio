# まごころパン屋 デモアプリケーション

## 実行環境の必要条件
- PHP >= 8.0 (PDO対応)
- MySQL >= 5.7 または MariaDB
- Webサーバー (Apache, Nginx, またはPHP内蔵サーバー)

## アプリケーションの概要
- まごころパン屋は、美味しいパンの閲覧・購入から、会員登録、ログイン、決済情報管理、電子領収書の発行、さらに売上や予約の管理までを体験できるPHP製のWebアプリケーションです。
- ユーザーは会員としてお気に入りのパンをカートに入れ、お受け取り日時を指定して注文を行うことができます。
- 管理者は、売上や予約状況の集計データを確認したり、ユーザーの検索を行うことができます。
- 参考データベース設定：`bakery_demo` (文字コード: `utf8mb4`, ユーザー: `user1`, パスワード: `passwordA1!`)

## 使い方
- トップページ（index.php）からログインまたは新規会員登録を行う。
- ショップ画面でパンを選び、カートに入れて購入手続き（受取日時・カード情報の入力）を進める。
- 注文完了後、電子領収書をダウンロードしたり、管理者画面で予約状況を確認する。

## 実装機能
### 共通基本機能
- PHPとPDOを用いたMySQLデータベースへの安全な接続とデータ処理
- セッション管理機能によるログイン状態の保持とアクセス制御

### 主要機能
- **店舗紹介・トップページ (`begin.php`)**:
    * お店のこだわりや新着情報、おすすめの特製クロワッサンを紹介 
- **認証・会員登録機能 (`index.php`)**:
    * ユーザーID・パスワードによるログイン、およびクレジットカード情報を含んだ新規会員登録
- **ショップ・カート・決済機能 (`shop.php`, `complete.php`)**:
    * 商品一覧・詳細の表示、カスタマーレビューの投稿、ショッピングカート機能
    * お受け取り日時の指定とクレジットカード情報の登録・更新による注文確定処理
- **電子領収書発行機能 (`download.php`)**:
    * 注文内容やマスクされたカード情報を記載した `電子領収書.txt` の自動ダウンロード
- **管理者ダッシュボード (`admin.php`)**:
    * 管理者権限を持つユーザーのみアクセス可能
    * 予約・売上データの集計表示と、キーワードによる予約詳細検索


### メモ
- 管理者画面では、データベースの構造を活かしたデータ表示と検索機能が実装されています。
